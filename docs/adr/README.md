# Registros de Decisões Arquiteturais

ADRs registram decisões relevantes quando preservar seu contexto ajudará trabalhos futuros. Use nomes sequenciais (`NNNN-titulo-curto.md`) e registre status, contexto, decisão e consequências. Não reconstrua justificativas históricas que o repositório não possa sustentar.

O diretório contém atualmente exatamente um registro de decisão.
